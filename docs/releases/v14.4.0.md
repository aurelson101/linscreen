# LinScreen 14.4.0

- First standalone x86_64 Flatpak bundle, distributed through GitHub Releases
  and the LinScreen website. This is not a Flathub publication.
- KDE/Qt 6.10 runtime, pinned source dependencies and verified language-model
  checksums. Tesseract, Leptonica and French/English models are bundled: OCR
  does not require installing Tesseract on the host.
- No network permission, host-command execution permission or unrestricted home
  access. Wayland/file portals are used where supported, with X11 fallback and
  direct Pictures access. Desktop portal packages are still required on the host.
- An isolated, clean-source packaging script records the source revision, refuses
  unsafe output directories and creates a versioned bundle and checksum.
- Release CI builds/tests the bundle, installs it and checks real OCR inside the
  runtime before publication. The Flatpak is covered by release SHA-256 checksums.
- OCR corrections are preserved when recognition fails, is cancelled or returns
  no text. The dialog explains when previous text has been kept.

Install the downloaded bundle with:

```sh
flatpak install --user ./LinScreen-14.4.0-x86_64.flatpak
flatpak run org.linscreen.LinScreen
```

Flatpak and access to Flathub for the KDE runtime are required. Updates to this
standalone bundle are installed manually; no automatic update repository is
configured. Existing DEB and AppImage distribution remains available.

Native GNOME/KDE end-to-end capture validation is separate from headless tests.
Signed Windows/macOS releases still require publisher credentials.
