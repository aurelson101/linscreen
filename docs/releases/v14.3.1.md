# LinScreen 14.3.1

- OCR actions stack vertically in narrow windows instead of forcing a wide
  horizontal button row. The layout also accounts for button text size.
- A new offscreen interface test checks resizing between compact and desktop
  layouts, disabled controls during recognition, editable results and explicit
  copying of corrected text. Opening the dialog and finishing recognition must
  leave the clipboard unchanged.
- Local French/English OCR still uses optional system Tesseract; other capture
  tools work without it. Linux packages include updated checksums and SBOM.
- Signed Windows/macOS releases still require publisher certificates and
  notarization credentials. Development builds are compatibility checks only.
