# LinScreen 14.1.1

Released: 2026-10-17

## Highlights

- Publishes the responsive Qt interface for GNOME, KDE Plasma, XFCE, and other
  Linux desktops, preserving the system theme and adapting window sizes to the
  available display area.
- Makes every configuration panel scrollable so settings remain accessible on
  small screens and with large fonts or high-DPI scaling.
- Improves capture dialog spacing, scrollable tabs, keyboard activation, and
  accessible names for region coordinates.
- Rejects empty, incomplete, and locale-dependent coordinate input before
  starting a capture, while preserving zero-size regions for interactive
  selection and negative coordinates for multi-monitor layouts.
- Locks capture settings while a screenshot is pending and restores controls
  on success or failure, preventing changes during the countdown.
- Checks packaged binaries, AppStream metadata, and Debian installation before
  publishing Linux release assets.
