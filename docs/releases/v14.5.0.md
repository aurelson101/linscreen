# LinScreen 14.5.0

## Capture tools and monitor selection

- Add an **All tools** menu during capture, also available with **Ctrl+Space**.
  It exposes available actions including local OCR and opaque redaction even
  when an older toolbar preference hides their buttons. Toolbar preferences
  are preserved; the existing right-click color picker remains unchanged.
- Display shortcuts and the active tool in the menu, with undo/redo availability
  synchronized with the undo stack. The new shortcut is configurable.
- Add an explicit **Selected Monitor** capture mode on Linux/Windows. Full
  Screen continues to capture the entire desktop and no longer displays an
  ineffective monitor selector. Region fields are synchronized on opening.
- Keep the floating toolbar within compact screen bounds, restore normal button
  sizes when space is available, and correct hit-testing of wrapped buttons.
- Add regression coverage for the tools menu, compact toolbar geometry and
  monitor request parameters without capturing a user's real desktop.
- Update French labels for the new capture controls.

## Packaging and validation scope

The Release workflow archives DEB, AppImage, standalone Flatpak, Linux tarball,
SBOM and signed checksums even for an explicitly non-publishing build.
Building packages does not publish a GitHub release or change the public site.

The standalone Flatpak keeps `org.linscreen.LinScreen`. The separate local
technical candidate is not part of this release or a Flathub submission.
Headless tests do not establish native GNOME/KDE/XFCE capture or portal behavior.
Windows/macOS trusted releases still require signing/notarization credentials.
