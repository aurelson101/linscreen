# LinScreen 14.1.0

Released: 2026-10-15

## Highlights

- Adds explicit XFCE, Cinnamon, MATE, and LXQt detection, with automatic native
  X11 capture fallback when a desktop portal is unavailable.
- Removes shell command construction from the Windows CLI launcher.
- Bounds and validates D-Bus/secondary-instance payloads and updater responses.
- Stores local history and configuration with owner-only permissions; upload
  deletion tokens are no longer embedded in preview filenames.
- Pins GitHub Actions and AppImage build tools, adds CodeQL/ShellCheck,
  CycloneDX SBOM generation, and keyless Sigstore signing of release checksums.
