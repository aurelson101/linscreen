# LinScreen 14.2.0

Released: 2026-10-17

- Cancel a delayed capture with the Cancel capture button or Escape. Closing
  the launcher also cancels its pending timer. The capture request is not
  submitted until the timer expires. A portal request already started cannot
  be cancelled from the launcher.
- Use the new Redact tool (Shift+R) to cover manually selected sensitive areas
  with opaque black. Its opacity does not depend on the drawing color or brush
  size. Saved/copied raster images contain the mask; the original remains in
  memory and undoable while editing. This does not detect sensitive text
  automatically or erase other copies of the original image.
- Open About > Capture diagnostics to review, refresh, and copy a local report
  of the desktop, screen geometry/scaling, and desktop portal availability.
  Reports omit usernames, hostnames, filesystem paths, screen names, raw
  environment variables, screenshots, and credentials. Nothing is uploaded.
- Add regression tests for opaque PNG exports at multiple display scales and
  diagnostic report privacy with injected sensitive environment values.

Linux downloads include AppImage, Debian package, Linux tarball, CycloneDX SBOM,
SHA-256 checksums and a Sigstore signature bundle. Signed Windows and macOS
publication still requires configured signing credentials.
