# LinScreen 14.4.1

First published standalone x86_64 Flatpak bundle, with all features described in
the [14.4.0 notes](v14.4.0.md). Version 14.4.0 was tested locally but its public
release was blocked by missing elfutils in the CI runner; its tag is retained.

- Bundle Tesseract, Leptonica and French/English OCR models inside the sandbox.
- No app network permission or unrestricted home access; retain Wayland/file
  portals, fallback X11, direct Pictures access and KDE theme settings.
- Preserve corrected OCR text after failed, cancelled or empty recognition.
- Add the native builder's required elfutils dependency and fail early if absent.
- Allow explicit manual publication after every package build and test passes,
  refusing to replace an existing release tag from another commit.
- Provide DEB, AppImage and Flatpak files with release SHA-256 checksums.

```sh
flatpak install --user ./LinScreen-14.4.1-x86_64.flatpak
flatpak run org.linscreen.LinScreen
```

This is a direct-download bundle, not a Flathub app listing. The KDE runtime is
downloaded from Flathub if needed. Bundle updates are installed manually.
Native desktop capture tests are separate from headless/runtime OCR tests.
Signed Windows/macOS releases still need publisher credentials.
