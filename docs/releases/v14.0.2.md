# LinScreen v14.0.2

Wayland reliability and release hardening update.

## Fixed

- Wayland capture now reports an unavailable D-Bus session cleanly instead of risking a crash.
- AppImage packaging refuses unsafe `APPDIR` paths and removes stale output before rebuilding.
- Debian and AppImage packaging use isolated CMake build trees to prevent stale Qt MOC output.
- GitHub publication no longer force-moves an existing release tag.
- AppImage CI derives artifact names from the project version.
