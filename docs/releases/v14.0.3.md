# LinScreen v14.0.3

Debian compatibility and release reliability update.

## Fixed

- Debian runtime dependencies are generated from the compiled binary, including Ubuntu `t64` package names where required.
- CI now installs the generated Debian package to detect unsatisfied dependencies.
- Debian and AppImage builds use isolated CMake trees, preventing stale Qt MOC output.
