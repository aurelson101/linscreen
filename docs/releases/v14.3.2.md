# LinScreen 14.3.2

- Fix the About window's intrinsic size: the application icon is limited to
  64 logical pixels, with high-DPI rendering, rather than its source size.
- Version and operating-system details wrap instead of forcing a wide window.
- About content scrolls vertically in compact windows, while Copy Info and
  Capture diagnostics stay outside the scroll area and remain accessible.
- Initial window dimensions respect the available screen area. Native Qt
  styling and system colors are retained; no GNOME/KDE-specific palette is forced.
- A regression test exercises available Qt widget styles with an 18-point
  font, 2x scaling, long text, compact/expanded dimensions, clipboard copying
  and Escape-to-close. This is not an end-to-end test of native GNOME/KDE sessions.

Local OCR and the existing capture tools are unchanged. Signed Windows/macOS
releases still require publisher signing/notarization credentials.
