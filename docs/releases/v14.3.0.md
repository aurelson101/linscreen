# LinScreen 14.3.0

## Local French/English OCR

- Extract text from a selected capture with the new OCR tool (Shift+T).
- Choose French, English or both; review and correct the editable result before
  explicitly copying it. Recognition never automatically changes the clipboard.
- Images are sent through memory to the optional local Tesseract executable,
  without cloud requests or temporary image files created by LinScreen.
- OCR uses the edited image, respecting opaque redactions rather than reading
  the original capture. Recognition is not automatic redaction or a guarantee
  of accuracy.
- Cancel a running recognition or close its window. Processing has a 30-second
  deadline, a 16-million-pixel/16-MiB PNG input limit and a 1-MiB text limit.
- Engine arguments are fixed and languages allowlisted; errors do not expose
  raw engine diagnostics. Missing engine/language data is reported in the UI.

On Debian/Ubuntu, install optional dependencies with:

```sh
sudo apt install tesseract-ocr tesseract-ocr-fra tesseract-ocr-eng
```

The AppImage also uses the system Tesseract installation. Other capture and
annotation tools remain usable without OCR dependencies.

## Packages and verification

Linux AppImage, DEB and tarball builds include checksums, a CycloneDX SBOM and
Sigstore attestation. Automated tests cover a real Tesseract recognition and
engine failures, cancellation, restart, timeout, invalid input and output limits.

Windows/macOS development builds remain compatibility checks. Public signed
releases still require publisher certificates and macOS notarization credentials;
this release does not claim to eliminate antivirus or operating-system warnings.
